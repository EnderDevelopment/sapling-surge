# Minecraft Datapack: Sapling Surge

Sapling Surge is a Minecraft datapack that doubles leaf-block sapling drop chances when leaves are broken, destroyed by explosions, or decay naturally. It includes updated loot tables for oak, spruce, birch, jungle, acacia, dark oak, mangrove, cherry, pale oak, azalea, and flowering azalea leaves.

## Install

1. Download or copy the Sapling Surge datapack folder.
2. Place it in the `datapacks` folder of your Minecraft Java Edition world.
3. Open or restart the world.
4. Run `/reload` if the world was already open.
5. Run `/datapack list` to confirm that Sapling Surge is enabled.

The datapack targets Minecraft Java Edition 26.2 and uses pack format 102.

## Use

1. Break leaf blocks normally, or allow them to decay after connected logs are removed.
2. Destroy leaf blocks with explosions.
3. Collect the resulting saplings or plantable drops.

Sapling Surge preserves the standard leaf loot behavior, including shears, Silk Touch, sticks, apples from oak leaves, and explosion survival checks. It changes the configured sapling or propagule chances to twice their standard values.
